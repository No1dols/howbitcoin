# howbitcoin
HowBitcoin — jednostavni vodič za korištenje, sigurnost i razumijevanje Bitcoina.
Cilj projekta je pomoći početnicima razumjeti:

- kako kupiti Bitcoin
- kako sigurno čuvati Bitcoin
- što je self custody
- kako koristiti Bitcoin
- kako izbjeći greške i prevare

Projekt je fokusiran na jednostavna objašnjenja i praktično znanje.
